# LAMMF — Python dependencies
# Tested on Python 3.10-3.13. If starting fresh, Python 3.11 or 3.12 is safest.
#
# RECOMMENDED SETUP:
#   1. Create a fresh environment (see SETUP.md), Python 3.12.
#   2. Install PyTorch FIRST, per the official selector at https://pytorch.org
#      - If the machine has an NVIDIA GPU, pick the CUDA build (much faster training).
#      - If not, pick the CPU build.
#   3. Then:   pip install -r requirements.txt
#   4. Check:  pip check   (should say "No broken requirements found")

# ---- CRITICAL PIN ----
# pydicom 3.x breaks pydicom-seg (the NSCLC mask converter). MUST be <3.
pydicom==2.4.4
pydicom-seg==0.4.1

# ---- numpy: keep on 1.x; numpy 2.x breaks pydicom-seg and several other deps ----
numpy<2

# ---- core data / ML ----
pandas
scikit-learn
tqdm
joblib
openpyxl             # reads the HNSCC clinical Excel sheet

# ---- imaging + radiomics ----
SimpleITK
mirp                 # IBSI radiomics (replaces PyRadiomics, which won't install on 3.13)

# ---- HNSCC masks ----
# convert_rtstruct_hnscc.py fills the contours itself (numpy + scipy, which comes
# with scikit-learn), so rt-utils and OpenCV are NOT needed.
# If you ever install rt-utils or OpenCV anyway: OpenCV >= 4.12 requires numpy 2,
# which silently upgrades numpy and breaks pydicom-seg. Hold it back with
#   pip install "numpy<2" "opencv-python<4.12" "opencv-python-headless<4.12"

# ---- deep learning ----
# NOTE: install torch FIRST from pytorch.org (see setup above), THEN these.
# torch_geometric must match the installed torch version.
torch
torch_geometric

# ---- only needed because Model_.py still imports them for the (unused) text branch ----
# If you delete the text-branch imports at the top of Model_.py, you can drop these two.
monai
transformers
